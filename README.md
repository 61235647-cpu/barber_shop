# 💈 Barber Shop

Aplicación web responsive para ayudar a barberos a organizar su negocio.

## Funciones
- 📅 Agenda y gestión de citas
- 👥 Registro y búsqueda de clientes
- ✂️ Catálogo de servicios y precios
- 💰 Cálculo de ingresos por citas completadas
- 📊 Reportes básicos
- 📱 Diseño adaptable para celular, tablet, laptop y PC
- 💾 Datos guardados localmente en el navegador

## Tecnologías
HTML5 · CSS3 · JavaScript · LocalStorage

## Uso
Abre `index.html` en un navegador. Para publicar con GitHub Pages, selecciona la rama `main` y la carpeta `/ (root)` en **Settings → Pages**.
